Generic Window Service Version 1.0 Release Notes

Platform Integration Toolkit Version 2.1

 

October 31, 2007

 

 

About this release

 

Product teams recognize that certain platform integration aspects are important to their customers but they lack development resources to implement changes.  To alleviate some of these issues, the idea of the Platform Integration Toolkit was introduced.  The intent of the Platform Integration Toolkit is to assist the developer for the supported mid-market platforms in providing the platform integration requirements.

 

New in this release

 

There are no changes in this release of the Generic Window Service.

Contacting customer support

This component is distributed and supported through the IBM Community Source Web site (http://cs.opensource.ibm.com/). To give suggestions or recommendations about the Platform Information Toolkit component, post a message on the Platform Information Toolkit community source project.

Getting access to IBM Community Source

To get access to IBM Community Source Web site, perform these tasks:

  • If you are a first-time user, sign in with your intranet user ID to register. Follow the instructions. Registration requires management approval.
  • Once registered in IBM Community Source, you need to request access to the "Platform Information Toolkit" project. Search for “Platform Information Toolkit”. On the project page, select "Request to join" in the upper right.
  • You are added to the project when the request is received and you will then be able to access the complete project. Your manager needs to approve this too.
  • When you access the project page, be sure to sign in so you can access everything available to you.

Defects, feature, and help requests

The Platform Information Toolkit development team monitors the Trackers page of the Platform Information Toolkit project in the IBM Community Source Web site.

  • Submit defects in the "Bugs Tracking System" section of the Trackers page.  Specifically identify the Generic Window Service component in the description.
  • Submit feature requests in the "Feature Requests Tracking System" section of the Trackers page.  Specifically identify the Generic Window Service if appropriate.
  • Submit questions in the "Help" section of the Forums area.
