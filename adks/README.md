# SDI ADKs

This repository contains a copy of the external ADKs which are used in SDI.

**NB**: In v10.0.0 a change was made to the build to use [Apache Ant Ivy](https://ant.apache.org/ivy/) to automatically download the dependencies from the Maven repository.  This is defined in the [ivy.xml](https://github.ibm.com/sec-di/SDI/blob/main/ivy.xml) file.  Only those ADKs which are not available in the Maven repository should be included in this repository.
