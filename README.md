# SyncWeave

SyncWeave is the official open-source version of IBM Verify Directory Integrator (VDI). It makes VDI accessible to the community under an open-source model, enabling contributions to be submitted, reviewed, and accepted into future VDI releases.

## Overview

SyncWeave is an enterprise-grade tool for the real-time synchronization and transformation of identity data across heterogeneous repositories. As identity schemas vary significantly between systems, SyncWeave not only moves data but also transforms records as they flow. It applies configurable attribute mapping rules and data transformations expressed through
Java/JavaScript to align data formats. SyncWeave includes a rich library of built-in connectors and a Java development environment for building or extending connectors as needs evolve.
It helps in building one AssemblyLine at a time, and each step can be run and tested immediately. It further simplifies integration by abstracting away the technical differences
between data sources.

Key Benefits and Capabilities:

• Create integration solutions by using the Configuration Editor

• Run integration solutions by using the Runtime Server

• Synchronize data across multiple repositories

• Transform data between different schemas

|---|---|
| AIX | POWER (PPC64) |
| Linux | x86-64 |
| Linux | zSeries / s/390 |
| Windows | x86-64 |

## Documentation

For comprehensive documentation on SyncWeave please visit the [official IBM documentation](https://www.ibm.com/docs/en/vdi/11.0.0).

Note that SyncWeave currently supports on-premises deployments. While the documentation also includes information related to container-based deployments, those sections apply to IBM Verify Directory Integrator (VDI). They are not supported as part of the SyncWeave open-source project.
