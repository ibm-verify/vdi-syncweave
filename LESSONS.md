# LESSONS.md

## Purpose

We store durable engineering decisions here so we do not lose context, repeat debates, or drift from agreed direction.

## Decision Log

### 2026-09-05 - Team Engineering Baseline

We agreed on the following baseline:

- We follow 12 Factor Application principles.
- We use Gang of Four patterns when they make code simpler to reason about and easier to evolve.
- We use BDD with Gherkin from unit tests through end-to-end tests.
- We follow Git Flow and do not commit directly to main or develop.
- We make elegant, simple, DRY changes that junior engineers can understand and extend.
- We keep change intent in CHANGE.md before implementation begins.
- We document code and files in first person plural, as a step-by-step journey, with an informal tone and light humor.
