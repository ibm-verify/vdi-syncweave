El panel de instrumentos facilita el trabajo con soluciones SDI. Se trata de un lugar único para desplegar soluciones SDI, configurarlas y gestionarlas. También se pueden crear integraciones simples sin tener que utilizar el editor de configuración de Eclipse.

*Nota: el panel de instrumentos funciona con soluciones que se hayan cargado en este servidor. Esto se puede hacer desde Eclipse, en el panel de instrumentos o copiando archivos. (enlace a más información) El panel de instrumentos consta de estos elementos principales: Panel principal (a la izquierda)

  • Cargar nueva solución
  • Enlace para configurar y supervisar páginas
Información del servidor
  • Información sobre el servidor DSI y los conectores instalados
  • Inspeccionar el registro de servidor principal
  • Gestionar almacén del sistema
Configurar soluciones
  • Definir y modificar propiedades de solución
  • Configurar y probar conectores
  • Modificar correlación de atributos en conectores
  • Ejecutar líneas de ensamblaje
  • Planificar líneas de ensamblaje
Supervisar soluciones
  • Estado en tiempo real de líneas de ensamblaje
  • Historial, estadísticas y registros de líneas de ensamblaje
  • Iniciar y detener líneas de ensamblaje.
EasyETL
  • Crear líneas de ensamblaje simples con conectores únicos de origen y destino
Una secuencia de eventos típica utilizando el panel de instrumentos sería:
  1. Cargar la solución, opcionalmente como "plantilla". Una solución podría ser un único archivo de configuración XML de SDI, pero también podría ser un archivo ZIP que incluya los archivos de propiedades necesarios para que la solución funcione correctamente.
  2. Crear una nueva solución a partir de una plantilla. Este paso puede saltarse si la solución se ha cargado sin convertirla en una plantilla.
  3. Configurar la solución. Esto podría incluir definir propiedades, configurar y probar los conectores y posiblemente ejecutar líneas de ensamblaje. Esto depende de la naturaleza de la solución.
  4. Planificar las líneas de ensamblaje para su ejecución.
  5. Supervisar soluciones
  6. Ver historial de ejecución
  7. Inspeccionar registros
  8. Opcionalmente, crear un informe de ejecución que periódicamente enviará un correo electrónico con el estado de las líneas de ensamblaje seleccionadas.
