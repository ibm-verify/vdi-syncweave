The Dashboard makes it simple to work with SDI solutions. It's a single place to deploy SDI solutions, configure, and manage them over time. Simple integrations can also be created without having to use the Eclipse configuration editor.

*Note: The Dashboard works with solutions that have been uploaded to this server. This can be done from Eclipse, in the Dashboard, or copying files. (link to more information) The Dashboard consist of these main elements: Main panel (on the left)

  • Upload new solutions
  • Link to configure and monitor pages
Server Info
  • Information about the SDI server and installed connectors
  • Inspect the main server log
  • Manage system store
Configure solutions
  • Set and modify solution properties
  • Configure and test connectors
  • Modify attribute mapping in connectors
  • Run AssemblyLines
  • Schedule AssemblyLines
Monitor solutions
  • Real-time status of AssemblyLines
  • History, statistics and logs of AssemblyLines
  • Start & stop AssemblyLines.
EasyETL
  • Build simple AssemblyLines with single source and target connectors
A typical sequence of events using the Dashboard would be
  1. Upload solution, optionally as "template". A solution could be a single SDI XML configuration file, but could also be a zip file that includes necessary property files for the solution to function properly.
  2. Create new solution from template. This step would be skipped if the solution was uploaded without turning it into a template.
  3. Configure the solution. This could include setting properties, configuring and testing the connectors and possibly running setup AssemblyLines. This depends on the nature of the solution.
  4. Schedule AssemblyLines for execution.
  5. Monitor solutions
  6. Watch execution history
  7. Inspect logs
  8. Optionally create RunReport which will periodically send an email with the status of the selected AssemblyLines.
