Das Dashboard vereinfacht die Arbeit mit TDI-Lösungen. Es bietet einen zentralen Punkt für die Implementierung von TDI-Lösungen sowie deren Konfiguration und Verwaltung. Die Erstellung einfacher Integrationen ohne die Verwendung des Eclipse-Konfigurationseditors ist ebenfalls möglich.

*Hinweis: Das Dashboard arbeitet mit Lösungen, die auf diesen Server hochgeladen wurden. Dies kann über Eclipse bzw. im Dashboard oder über das Kopieren von Dateien erfolgen. (Link für weitere Informationen) Das Dashboard besteht aus den folgenden Hauptelementen: Hauptanzeige (auf der linken Seite)

  • Upload neuer Lösungen
  • Link zum Konfigurieren und Überwachen von Seiten
Serverinformationen
  • Informationen zum TDI-Server und zu den installierten Komponenten
  • Überprüfen des Hauptserverprotokolls
  • Verwalten des Systemspeichers
Konfigurieren von Lösungen
  • Definieren und Ändern von Lösungseigenschaften
  • Konfigurieren und Testen von Connectors
  • Ändern der Attributzuordnung in Connectors
  • Ausführen von Fertigungslinien
  • Zeitplanung für Fertigungslinien
Überwachen von Lösungen
  • Echtzeitstatus von Fertigungslinien
  • Verlauf, Statistik und Protokolle für Fertigungslinien
  • Starten und Stoppen von Fertigungslinien
EasyETL
  • Erstellen einfacher Fertigungslinien mit einzelnen Quellen- und Zielconnectors
Typische Ereignisfolge bei der Verwendung des Dashboards:
  1. Upload einer Lösung, optional als Schablone. Eine Lösung kann eine einzelne TDI-XML-Konfigurationsdatei sein, aber auch eine Zip-Datei, die die erforderlichen Eigenschaftendateien für die korrekte Ausführung der Lösung enthält.
  2. Erstellen einer neuen Lösung aus einer Schablone. Dieser Schritt wird übersprungen, wenn die Lösung hochgeladen wird, ohne sie zu einer Schablone zu machen.
  3. Konfigurieren der Lösung. Hierzu gehört zum Beispiel das Definieren von Eigenschaften, das Konfigurieren und Testen der Connectors sowie gegebenenfalls die Ausführung von Konfigurationsfertigungslinien. Dies ist von der Art der Lösung abhängig.
  4. Zeitliche Planung der Ausführung von Fertigungslinien.
  5. Überwachen von Lösungen.
  6. Überwachen des Ausführungsverlaufs.
  7. Überprüfen der Protokolle.
  8. Optionale Erstellung eines Ausführungsberichts, der regelmäßig eine E-Mail mit dem Status der ausgewählten Fertigungslinien sendet.
