Le tableau de bord simplifie le travail avec les solutions TDI. Il constitue un emplacement unique permettant de déployer les solutions TDI, de les configurer et de les gérer dans le temps. Les intégrations simples peuvent également être créées sans l'aide de l'éditeur de configuration Eclipse.

*Remarque : Le tableau de bord est compatible avec les solutions ayant été téléchargées sur ce serveur. Cette action peut être effectuée à partir d'Eclipse, dans le tableau de bord ou via la copie de fichiers (lien vers les informations supplémentaires). Le tableau de bord est constitué des éléments principaux suivants : Panneau principal (à gauche)

  • Télécharger de nouvelles solutions
  • Lien vers les pages de configuration et de surveillance
Informations sur le serveur
  • Informations sur le serveur SDI et les connecteurs installés
  • Consulter le journal serveur principal
  • Gérer le magasin système
Configurer les solutions
  • Définir et modifier les propriétés des solutions
  • Configurer et tester les connecteurs
  • Modifier le mappage d'attributs dans les connecteurs
  • Exécuter les chaînes d'assemblage
  • Planifier les chaînes d'assemblage
Surveiller les solutions
  • Etat en temps réel des chaînes d'assemblage
  • Historique, statistiques et journaux des chaînes d'assemblage
  • Démarrer & arrêter les chaînes d'assemblage.
EasyETL
  • Générer des chaînes d'assemblage simples avec les connecteurs source et cible uniques
Une séquence typique d'événements utilisant le tableau de bord serait l'une des suivantes :
  1. Télécharger la solution, éventuellement comme "modèle". Une solution pourrait se présenter comme un fichier de configuration XML SDI unique, mais également comme un fichier zip incluant les fichiers de propriétés nécessaires au bon fonctionnement de la solution.
  2. Créer une nouvelle solution à partir du modèle. Sauter cette étape si la solution a été téléchargée sans être transformée en modèle.
  3. Configurer la solution. Cette action comprend la définition des propriétés, la configuration et le test des connecteurs et l'exécution éventuelle des chaînes d'assemblage d'installation. Cela dépend de la nature de la solution.
  4. Planifier les chaînes d'assemblage pour l'exécution.
  5. Surveiller les solutions.
  6. Observer l'historique d'exécution.
  7. Examiner les journaux.
  8. Créer éventuellement un rapport d'exécution qui enverra périodiquement un e-mail indiquant le statut des chaînes d'assemblage sélectionnées.
