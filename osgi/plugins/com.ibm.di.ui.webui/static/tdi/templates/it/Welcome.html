Il dashboard semplifica l'utilizzo delle soluzioni TDI. Consente di distribuire le soluzioni TDI, configurarle e gestirle nel tempo. Le integrazioni semplici possono anche essere create senza dover utilizzare l'editor di configurazione Eclipse.

*Nota: il dashboard utilizza le soluzioni che sono state caricate su questo server. È possibile eseguire questa operazione da Eclipse, nel dashboard o copiando i file. (link a ulteriori informazioni) Il dashboard è costituito da questi elementi principali: pannello principale (a sinistra)

  • Caricamento di nuove soluzioni
  • Link per configurare e controllare le pagine
Informazioni sul server
  • Informazioni sul server TDI e i connettori installati
  • Esame del log del server principale
  • Gestione dell'archivio di sistema
Soluzioni di configurazione
  • Impostazione e modifica delle proprietà di soluzione
  • Configurazione e verifica dei connettori
  • Modifica dell'associazione di attributi nei connettori
  • Esecuzione degli AssemblyLine
  • Pianificazione degli AssemblyLine
Controllo delle soluzioni
  • Stato in tempo reale degli AssemblyLine
  • Cronologia, statistiche e log degli AssemblyLine
  • Avvio & arresto degli AssemblyLine.
EasyETL
  • Creazione di AssemblyLine semplici con singoli connettori di origine e destinazione
Di seguito è riportata una tipica sequenza di eventi utilizzando il dashboard
  1. Caricamento della soluzione, facoltativamente come "modello". Una soluzione potrebbe essere un singolo file di configurazione XML TDI, ma potrebbe anche essere un file zip che include i file delle proprietà necessari per il corretto funzionamento della soluzione.
  2. Creazione di una nuova soluzione dal modello. Questo passo viene ignorato se la soluzione è stata caricata senza modificarla in un modello.
  3. Configurazione della soluzione. Ciò potrebbe includere l'impostazione delle proprietà, la configurazione e la verifica dei connettori e l'eventuale esecuzione degli AssemblyLine di impostazione. Ciò dipende dalla natura della soluzione.
  4. Pianificazione degli AssemblyLine per l'esecuzione.
  5. Controllo delle soluzioni
  6. Osservazione della cronologia di esecuzione
  7. Esame dei log
  8. Creazione facoltativa di RunReport che invia periodicamente un messaggio e-mail con lo stato degli AssemblyLine selezionati.
