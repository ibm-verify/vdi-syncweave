Dashboard Security Settings

These settings determine who can access the Dashboard. There are separate settings for local and remote users.

The option for local and remote connections is one of the following values
  • none - Disables authentication and allows all connections
  • deny - Disables access for all connections
  • ldap - Authentication with an LDAP server before permitting access

LDAP server settings - These settings are used to authenticate a user. Users can type their distinguished name (e.g. cn=john doe,ou=orgunit,o=org) or their mail address in which case a search is made for a single unique match.

Local - Connections originating from one of the local host's addresses
Remote - Connections originating from non-local hosts
LDAP Hostname - Specify hostname[:port] for the LDAP server.
LDAP Search base - If specified users can enter their mail address and a search will be made to locate the user's distinguished name. If not specified, users must provide their full distinguished name.
LDAP Group DN - If specified users are checked for membership

Updating these settings take immediate effect.
