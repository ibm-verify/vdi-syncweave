Security Verify Directory Integrator 中的 JavaScript

此页面提供了 JavaScript 片段，您可以从中学习并将其剪切/粘贴到解决方案中。 因特网上有许多 JavaScript 资源，因此此页面仅用于快速介绍您可以使用 JavaScript执行的操作。

JavaScript 用于属性映射 (AM) ，挂钩，脚本，条件分支和参数替换。 在 AMs 中， Javascript 需要向属性返回新值。 左侧列显示了有关如何完成此操作的一些变体。

要学习的最实用的工具是，您可以在脚本编制时随时按 Control-space 键组合以获取有效属性和功能的列表。 此外，每当您输入句点 "." 时， 编辑器将在该阶段显示有效选项。

JavaScript 规范称为 ECMAscript ，此处记录了最新版本: www.ecmascript.org/docs/tc39-2009-043.pdf
