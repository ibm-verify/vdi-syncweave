Esta página proporciona fragmentos de JavaScript de los que puede aprender y cortar/pegar en la solución. Hay una serie de recursos JavaScript en Internet, por lo que esta página sólo pretende ser una introducción rápida a lo que puede hacer con JavaScript.

JavaScript se utiliza en correlaciones de atributos (AM), enganches, scripts, ramas condicionales y sustitución de parámetros. En los AMs, el Javascript necesita devolver un nuevo valor a un atributo. La columna izquierda muestra algunas variaciones sobre cómo se hace.

La herramienta más práctica para aprender es que puede pulsar la combinación de teclas Control-espacio para obtener una lista de los atributos válidos y la función en cualquier momento durante el script. Además, siempre que escriba un punto ".", el editor mostrará las opciones válidas en esa etapa.

La especificación JavaScript se denomina ECMAscript, la versión más reciente se documenta aquí: www.ecmascript.org/docs/tc39-2009-043.pdf

Llamada y utilización de un conector desde un script

Hay varias formas de crear un script para un conector. Si tiene un conector denominado myLDAP en la línea de ensamblaje, por ejemplo:

ldap = myLDAP.getConnector();
ldap.setParam("ldapSearchFilter", "(& (cn = GRP-* ...");
ldap.terminate();
ldap.initialize(); // o myLDAP.reconnect ();

en esta etapa puede recuperar registros como este:

ldap.selectEntries();
e = ldap.getNextEntry();
while (e! = null) {
// hacer algo con él
e = ldap.getNextEntry ();
