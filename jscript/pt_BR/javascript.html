JavaScript é usado em mapas de atributos (AM), ganchos, scripts, ramificações condicionais e substituição de parâmetro.. Em AMs o Javascript precisa retornar um novo valor para um atributo. A coluna esquerda mostra algumas variações sobre como isso é feito.

A ferramenta mais prática para aprender é que é possível pressionar a combinação de teclas Control-space para obter uma lista dos atributos e funções válidos a qualquer momento durante o script. Além disso, sempre que você digitar um ponto ".", o editor exibirá as opções válidas nesse estágio.

A especificação JavaScript é chamada ECMAscript, a versão mais recente é documentada aqui: www.ecmascript.org/docs/tc39-2009-043.pdf

Alterando um Valor em um Mapa de Atributo

O exemplo mais simples é quando você retorna um valor fixo, como
1 (para um valor inteiro) ou "yes" (para um valor de sequência)

Quando desejar modificar o conteúdo de um atributo e usar seu valor
existente como parte do novo valor, será necessário prefixar o nome do atributo
com "conn." Por exemplo:
conn.attributeName + " inclui esse texto no valor "
ou
" ("+ conn.attribute1 +", " + conn.attribute2 + ")"

há um grande número de funções disponíveis, como transformar uma sequência em maiúscula:
conn.myAttribute.getValue().toUpperCase ()

Tente as opções observando as opções que você obtém em cada estágio, como
após digitar:
conn.
conn.yourAttribute.
Con. yourAttribute.getValue().

Chamando e usando um Conector do script

Há várias maneiras de executar script em um Conector. Se você tiver um conector chamado myLDAP em sua Linha de Montagem, você poderia, por exemplo:

ldap = myLDAP.getConnector();
ldap.setParam("ldapSearchFilter", "(& (cn = GRP-* ...");
ldap.terminate();
ldap.initialize(); // ou myLDAP.reconnect ();

neste estágio é possível recuperar os registros como este:

ldap.selectEntries();
e = ldap.getNextEntry();
while (e! = null) {
// fazer algo com ele
e = ldap.getNextEntry ();
}
