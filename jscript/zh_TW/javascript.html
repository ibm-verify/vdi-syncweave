Security Verify Directory Integrator 中的 JavaScript

此頁面提供 JavaScript 的 Snippet ，您可以從中學習並剪下/貼上至解決方案。 網際網路上有許多 JavaScript 資源，因此此頁面僅作為您可以使用 JavaScript所執行的動作的快速簡介。

JavaScript 用於屬性對映 (AM)、連結鉤、Script、條件式分支及參數替代。 在 AMS 中， Javascript 需要將新值傳回至屬性。 左直欄會顯示一些有關如何完成的變異。

最實用的學習工具是您可以按「控制-空間」組合鍵，在 Scripting 時隨時取得有效屬性及功能的清單。 此外，每當您鍵入句點 "." 時， 編輯器將在該階段顯示有效的選項。

JavaScript 規格稱為 ECMAScript ，這裡說明最新版本: www.ecmascript.org/docs/tc39-2009-043.pdf
