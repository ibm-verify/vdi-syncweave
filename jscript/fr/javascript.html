JavaScript dans Security Verify Directory Integrator

Cette page fournit des fragments de JavaScript que vous pouvez utiliser et couper / coller dans votre solution. Il existe un certain nombre de ressources JavaScript sur Internet. Cette page n'est donc qu'une introduction rapide à ce que vous pouvez faire avec JavaScript.

JavaScript est utilisé dans les mappes d'attributs (AM), les points d'ancrage, les scripts, les branches conditionnelles et la substitution de paramètres. Dans les AM, Javascript doit renvoyer une nouvelle valeur à un attribut. La colonne de gauche affiche quelques variations sur la façon dont cela est fait.

L'outil le plus pratique à apprendre est que vous pouvez appuyer sur la combinaison de touches Espace de contrôle pour obtenir la liste des attributs et fonctions valides à tout moment lors de la génération de scripts. De plus, chaque fois que vous tapez un point ".", l'éditeur affichera les choix valides à ce stade.

La spécification JavaScript est appelée ECMAscript, la version la plus récente est documentée ici: www.ecmascript.org/docs/tc39-2009-043.pdf

Modification d'une valeur dans une mappe d'attributs

L'exemple le plus simple est celui où vous renvoyez une valeur fixe telle que
1 (pour une valeur entière) ou "yes" (pour une valeur de chaîne)

Lorsque vous souhaitez modifier le contenu d'un attribut et utiliser sa valeur
existante dans le cadre de la nouvelle valeur, vous devez préfixer le nom d'attribut
avec "conn." Par exemple:
conn.attributeName + " ajoute ce texte à la valeur "
ou
" ("+ conn.attribute1 +", " + conn.attribute2 + ")"

il existe un grand nombre de fonctions disponibles, telles que la transformation d'une chaîne en majuscules:
conn.myAttribute.getValue().toUpperCase ()

Essayez les options en regardant les options que vous obtenez à chaque étape, telles que
après avoir tapé:

str = conn.yourAttribute.getValue().toUpperCase () ;

Appel et utilisation d'un connecteur à partir d'un script

Il existe plusieurs manières de créer un script sur un connecteur. Si vous disposez d'un connecteur appelé myLDAP dans votre chaîne d'assemblage, vous pouvez par exemple:

ldap = myLDAP.getConnector() ;
ldap.setParam("ldapSearchFilter", "(& (cn = GRP-* ...");
ldap.terminate() ;
ldap.initialize() ; // ou myLDAP.reconnect () ;

à ce stade, vous pouvez extraire les enregistrements comme suit:

ldap.selectEntries() ;
e = ldap.getNextEntry() ;
while (e ! = null) {
// faire quelque chose avec
e = ldap.getNextEntry () ;
}
