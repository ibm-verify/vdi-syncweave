Security Verify Directory Integrator のJavaScript

このページには、学習してソリューションにカット・アンド・ペーストできる JavaScript のスニペットが表示されます。 インターネット上には多数の JavaScript リソースがあるため、このページは、 JavaScriptを使用してできることを簡単に紹介することのみを目的としています。

JavaScript は、属性マップ (AM)、フック、スクリプト、条件付きブランチ、およびパラメーター置換で使用されます。 AM では、Javascript は属性に新しい値を返す必要があります。 左側の列には、その方法に関するいくつかのバリエーションが示されています。

最も実用的なツールは、制御スペース・キーの組み合わせを押すと、スクリプト中にいつでも有効な属性と機能のリストを取得できることです。 また、ピリオド「.」を入力すると、 エディターは、その段階で有効な選択項目を表示します。

JavaScript 仕様の名前は ECMAscript で、最新バージョンは www.ecmascript.org/docs/tc39-2009-043.pdf

に記載されています。

スクリプトからのコネクターの呼び出しと使用

コネクターに対してスクリプトを作成するには、いくつかの方法があります。 AssemblyLine に myLDAP というコネクターがある場合は、次のようになります。

ldap = myLDAP.getConnector();
ldap.setParam("ldapSearchFilter", "(& (cn = GRP-* ...");
ldap.terminate();
ldap.initialize(); // または myLDAP.reconnect ();

この段階で、次のようなレコードを取得できます。

ldap.selectEntries();
e = ldap.getNextEntry()
while (e! = null) {
// それで何かを行う
e = ldap.getNextEntry ();
}
