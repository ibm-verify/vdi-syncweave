스크립트에서 커넥터 호출 및 사용

커넥터에 대해 스크립트하는 방법에는 여러 가지가 있습니다. If you have a connector called myLDAP in your Assemblyline you could for example:

    ldap = myLDAP.getConnector();
    ldap.setParam("ldapSearch필터", "(S = GRP - * ...");
    ldap.terminate();
    ldap.initialize();        // or myLDAP.reconnect();

at this stage you can retrieve the records like this:

    ldap.selectEntries();
    e = ldap.getNextEntry();
    반면에 (e ! = null) {
        // do something with it
        e = ldap.getNextEntry ();
    }


당신이 이 사실을 알고 싶어한다.
