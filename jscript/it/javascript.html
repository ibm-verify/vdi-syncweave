JavaScript in Security Verify Directory Integrator

Questa pagina contiene frammenti di JavaScript che è possibile tagliare/incollare nella propria soluzione. Su Internet sono disponibili diverse risorse JavaScript, per cui questa pagina rappresenta solo una breve introduzione alle operazioni che è possibile eseguire con JavaScript.

JavaScript viene utilizzato nelle mappe di attributi, negli hook, negli script, nelle risorse condizionali e nella sostituzione dei parametri. Nelle mappe di attributi, Javascript deve restituire un nuovo valore ad un attributo. La colonna di sinistra mostra alcune variazioni sulla modalità di esecuzione di tale operazione.

Lo strumento più pratico da utilizzare è quello che consente di utilizzare la combinazione di tasti Control-barra di spazio per visualizzare un elenco delle funzioni e degli attributi validi in qualsiasi momento durante la creazione dello script. Inoltre, ogni volta che si digita un punto ".", l'editor visualizzera ' le scelte valide in tale fase.

La specifica JavaScript è denominata ECMAscript, la versione più recente è documentata qui: www.ecmascript.org/docs/tc39-2009-043.pdf

L'esempio più semplice è quando si restituisce un valore fisso come
1 (per un valore intero) o "yes" (per un valore stringa)

Quando si desidera modificare il contenuto di un attributo e utilizzare il relativo valore
esistente come parte del nuovo valore, è necessario anteporre al nome attributo
"conn." Ad esempio:

Richiamo ed utilizzo di un connettore dallo script

È possibile creare uno script per un connettore in diversi modi. Se si dispone di un connettore denominato myLDAP nell'Assemblyline, è possibile, ad esempio:

    ldap = myLDAP.getConnector();
    ldap.setParam("ldapSearchFiltro", "(& (cn = GRP - * ...");
    ldap.terminate();
    ldap.initialize();    // o myLDAP.reconnect ();

in questa fase è possibile richiamare i record come riportato di seguito:

    ldap.selectEntries();
    e = ldap.getNextEntry();
    while (e! = null) {
// eseguire le operazioni
e = ldap.getNextEntry ();
    }
