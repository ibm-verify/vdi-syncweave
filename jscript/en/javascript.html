JavaScript in Security Verify Directory Integrator

This page provides snippets of JavaScript that you can learn from and cut/paste into your solution. There are a number of JavaScript resources on the Internet, so this page is only intended as quick introduction to what you can do with JavaScript.

JavaScript is used in attribute maps (AM), hooks, scripts, conditional branches, and parameter substitution. In AMs the Javascript needs to return a new value to an attribute. The left column show a few variations on how that's done.

The most practical tool to learn is that you can press the Control-space key combination to get a list of the valid attributes and function at any time while scripting. Also, whenever you type a period ".", the editor will display the valid choices at that stage.

The JavaScript specification is called ECMAscript, the most recent version is documented here: www.ecmascript.org/docs/tc39-2009-043.pdf

Changing a value in an Attribute Map

The most simple example is where you return a fixed value such as
1 (for a integer value) or "yes" (for a string value)

When you want to modify the contents of an attribute and use its existing
value as part of the new value, you have to prefix the attribute name
with "conn." For example:
conn.attributeName + " adds this text to the value"
or
"(" + conn.attribute1 + ", " + conn.attribute2 + ")"

there are a large number of functions available, such as turning a string to uppercase:
conn.myAttribute.getValue().toUpperCase()

Try the options by watching the options you get at each stage, such as
after typing:

conn. yourAttribute.getValue().

Dynamic attribute mapping

The below code checks if one attribute equals 1 and another one contains the string "yes" (you might want to uppercase the string so that you can handle all versions of case in the attribute).
Then it returns either the text Yes or No.

str = conn.yourAttribute.getValue().toUpperCase();
if (conn.yourOtherAttribute == 1 || str.indexOf("YES") >= 0 {
 return "Yes"
} else {
 return "No"
}

Calling and using a Connector from script

There are several ways to script against a Connector. If you have a connector called myLDAP in your Assemblyline you could for example:

    ldap = myLDAP.getConnector();
    ldap.setParam("ldapSearchFilter", "(&(cn=GRP-*...");
    ldap.terminate();
    ldap.initialize();        // or myLDAP.reconnect();

at this stage you can retrieve the records like this:

    ldap.selectEntries();
    e = ldap.getNextEntry();
    while (e != null) {
        // do something with it
        e = ldap.getNextEntry();
    }
