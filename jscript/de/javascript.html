JavaScript in Security Verify Directory Integrator

Diese Seite stellt Snippets von JavaScript bereit, die Sie aus Ihrer Lösung lernen und ausschneiden/einfügen können. Es gibt eine Reihe von JavaScript -Ressourcen im Internet, sodass diese Seite nur als schnelle Einführung in die Möglichkeiten von JavaScriptdient.

JavaScript wird in Attributzuordnungen (AM), Hooks, Scripts, bedingten Verzweigungen und Parametersubstitution verwendet. In AMs muss JavaScript einen neuen Wert an ein Attribut zurückgeben. Die linke Spalte zeigt einige Variationen darüber, wie das geht.

Das praktischste Tool, um zu lernen, ist, dass Sie die Tastenkombination Strg + Leertaste drücken können, um eine Liste der gültigen Attribute und Funktionen jederzeit während der Scripterstellung abzurufen. Außerdem gilt Folgendes: Wenn Sie einen Punkt "." eingeben, Der Editor zeigt die gültigen Auswahlmöglichkeiten in dieser Phase an.

Die JavaScript -Spezifikation hat den Namen ECMAscript. Die neueste Version ist hier dokumentiert: www.ecmascript.org/docs/tc39-2009-043.pdf

Wert in einer Attributzuordnung ändern

Das einfachste Beispiel ist, wenn Sie einen festen Wert wie
1 (für einen ganzzahligen Wert) oder "yes" (für einen Zeichenfolgewert)

zurückgeben, wenn Sie den Inhalt eines Attributs ändern und den vorhandenen Wert
als Teil des neuen Werts verwenden wollen, müssen Sie dem Attributnamen
das Präfix "conn." voranstellen. Beispiel:
conn.attributeName + " fügt diesen Text dem Wert "
oder
" hinzu ("+ conn.attribute1 +", " + conn.attribute2 + ")"

Es gibt eine große Anzahl von Funktionen, die verfügbar sind, wie z. B. die Umwandlung einer Zeichenfolge in Großbuchstaben:
conn.myAttribute.getValue().toUpperCase ()
