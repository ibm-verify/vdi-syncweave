1.0 Contributions to IBM Support Assistant

The SyncWeave feature enhances IBM Support Assistant by contributing configuration data to the various components available. The following categories provide details on the contributions provided in this feature:

1.1 Search

  • Search multiple Web sites simultaneously
  • Find Technotes and supporting technical information
  • Filter your searches based on SyncWeave versions
  • Contributes the Tivoli Storage Manager Server on-line Information Center to the available search targets

1.2 Product Information

  • Find important links to information about SyncWeave

1.3 Service

  • Collect data on your problem to speed up problem resolution
  • Manage your problem reports
  • Submit electronic service requests (ESR)

1.3.1 Data Collection

The list below documents the types of symptom-based, automated data collection provided in this feature. Each symptom will be available in the Service's data collection component for SyncWeave within IBM Support Asssistant.
  • General Problem - this collection gathers data necessary to debug general problems with SyncWeave
