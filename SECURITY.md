# Security Policy

All versions, unless otherwise stated, are supported with security updates.

## Reporting a Vulnerability

To report a security issue, open a issue through [request](https://github.com/ibm-verify/SyncWeave/issues). Make sure to add prefix "security" in the title. In the issue details, include the following:

Repository name
Description of the issue
Steps taken to create the issue
Affected versions
Mitigations for the issue, if known

Before submitting, please search for similar issues, as someone may have reported the same one already.
