# Security Policy

All versions, unless otherwise stated, are supported with security updates.

## Reporting a Vulnerability

To report a security issue, please open a issue through [request](https://github.com/ibm-verify/SyncWeave/issues). Make sure to add "VULNERABILITY" keyword ih the title. In the issue details, please add the repository name, a description of the issue, the steps you took to create the issue, affected versions, and if known, mitigations for the issue.
Before that, please search for similar issues. It's possible somebody has encountered this issue already. This project follows a 90 day disclosure timeline.
