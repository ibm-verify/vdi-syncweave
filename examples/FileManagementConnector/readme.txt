Using File Management Connector - An Example

Overview
This example shows how to use the File Management Connector to read and modify the file structures and available metadata on the system for the supported connector operation modes. This example configuration file is created using Windows x86 system, where SDI is installed with install directory as the solution directory. The example folder includes: 
 �  FileManagementConnector.xml - Security Verify Directory Integrator 7.2 configuration file, which contains six AssemblyLines as described in the following sections.
 �  readme.txt - provides information on how to run the example configuration file.
 �  fmc.properties - properties file, which is used to configure all AssemblyLines in the FileManagementConnector.xml configuration file.
 
Prerequisites to Run Example Configuration File
 �  Copy the example folder to your curren SDI solution directory. For example, if the current solution directory is SDI install directory>, the example folder path is: SDI install directory>\examples\FileManagementConnector\*.*
 �  Update the fmc.properties file with the correct solution directory path.

Running Example Configuration File
To run the configuration file:
1)  Start the SDI Configuration Editor.
2)  Import the FileManagementConnector.xml source file. To import a source file:
      a.  Go to File ->Import. The Import dialog window appears.
      b.  Select SyncWeave ->Configuration from the Select an import source list.
      c.  Click Next. The Import Security Verify Directory Integrator configuration dialog window appears.
      d.  In the Configuration File field, browse and select the FileManagementConnector.xml file.
      e.  Click Finish. The New Project dialog window appears.
      f.  Specify a project name in the Project name field.
      g.  Click Finish.
3) In the Navigator panel on the left side of the Configuration Editor window, expand AssemblyLines under the new project you created. 
4) Run the following AssemblyLines:
      �  cleanup 
      �  addonly 
      �  update 
      �  read 
      �  lookup 
      �  delete 
 
Description of AssemblyLines 
After configuring the fmc.properties file with correct solution directory path, run the cleanup AssemblyLine to: 
 �  Make the environment ready to run the example configuration file without errors. 
 �  Forcefully delete the testFolder folder, if it exists, under solution directory. 

Run the addonly AssemblyLine to:
 �  Read the SDI solution dir>/examples/FileManagementConnector/folderStructure.txt input file to create the following folders:
     � SDI solution dir>/testFolder
     � SDI solution dir>/testFolder/inside_testFolder
 �  Create a test.log file in the SDI solution dir>/testFolder folder with sample contents. 

Run the update AssemblyLine to:
 �  Move the test.log file from the SDI solution dir>/testFolder folder to the SDI solution dir>/testFolder/inside_testFolder folder.

Run the read AssemblyLine to:
 �  Recursively read the contents of SDI solution dir>/testFolder folder. 
 �  Dump the read contents into the SDI solution dir>/examples/FileManagementConnector/dump_dir_files_list.txt output file.
 
Run the lookup AssemblyLine to:
 �  Read the file generated by the read AssemblyLine and lookup for the Entries from the specified folder.

Run the delete AssemblyLine to:
 �  Read the file generated by the read AssemblyLine and forcefully delete each Entry from the specified folder.
